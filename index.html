                Compiler Theory: Target Code Generation vs. Program Execution
                
Generating assembly (Stage 5) is a static translation process: the compiler maps intermediate instructions into target architecture assembly without running the program. In contrast, program execution (Stage 6) is dynamic runtime evaluation: state registers mutate, memory is updated, and standard I/O functions emit characters to stdout.
